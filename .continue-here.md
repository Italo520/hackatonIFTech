### 🧠 Decisões Tomadas

| Decisão | Razão |
|---------|-------|
| GSAP via CDN (não via npm) | Evitar build step; documentação é página estática sem dependências |
| Progressive enhancement | Se CDN falhar, conteúdo fica visível sem animações |
| Dark-mode glassmorphism | Contraste visual com o admin (fundo claro) — destaca a documentação |
| Auto-submit filtros apenas em desktop | Mobile: evita recarregamentos excessivos a cada checkbox |
| Sem commits automáticos | Regra explícita do usuário: "só faça commits e push após solicitação" |
